V1 Core Features

Total Station

Field observations with Hz / ZA, slope distance, HI / HR and orientation. Point ID, Code and Description accompany coordinate calculations.

Traverse / Polygon

Loop, Link and Open workflows, closure checks, QC and Bowditch adjustment where applicable.

Differential Leveling

BS, IS, FS, TP and HI observations, Rise / Fall, arithmetic checks and applicable adjustment.

Detail Survey

Detail observations from survey stations, with raw observation preservation, calculated coordinates and station provenance.

Coordinate Transformation

3 Parameter, 7 Parameter Helmert, Position Vector / Coordinate Frame, 2D 4 Parameter Similarity, 2D 6 Parameter Affine, Geographic / ECEF and CRS conversion.

CRS & Project Profiles

WGS 84, UTM, Transverse Mercator, project coordinate systems and Indonesia project/block references, with explicit parameter provenance and verification status.

Coordinate Formats

Enter and present coordinates as DD, DDM or DMS.

Professional Export

TXT, CSV, XLSX and Survey DXF for field and calculation outputs, plus professional transformation reports.

Offline Guide

Indonesian and English guidance available without a continuous internet connection.

Professional Coordinate Transformation

Define the Source CRS and Target CRS, choose 3 Parameter or 7 Parameter Helmert with Position Vector / Coordinate Frame conventions, and work with project-specific parameters and their provenance. Review geographic and projected results and professional TXT/XLSX transformation reports.

Professional Field & Calculation Outputs

Export TXT, CSV, XLSX and Survey DXF for field records, calculation review and downstream survey workflows. Professional Transformation Reports document results and parameter provenance.

Built for Offline-first Work

Core calculations and project data are designed to remain available locally on the device. No account is required for current V1 core functionality. The offline guide supports Indonesian and English.
