AIQOLA Survey Field Tools Privacy Policy

Last updated: 3 October 2026

AIQOLA Survey Field Tools is developed and provided by AIQOLA — AI Automation & Digital Solutions.

Privacy & Support: hello@aiqola.com

1. Overview

AIQOLA Survey Field Tools is an offline-first professional surveying, mapping, coordinate calculation, quality-control, and field-support application.

Core application functions do not require a user account or continuous internet connection.

2. Data Stored on the Device

Survey projects, observations, coordinates, calculation results, transformation parameters, project profiles, and exported files are stored locally on the user's device or in storage locations selected by the user.

AIQOLA Survey Field Tools does not automatically upload survey projects, observations, coordinates, or calculation results to an AIQOLA server.

3. Personal Data Collection

The current version of AIQOLA Survey Field Tools does not require users to create an account.

The current version does not intentionally collect or transmit to AIQOLA:

  • names or personal profile information;
  • survey coordinates;
  • project files;
  • device advertising identifiers;
  • user activity for advertising;
  • precise location data;
  • contact lists;
  • photos or media;
  • payment information.

If application functionality changes in the future, this Privacy Policy and the Google Play Data Safety declaration will be updated accordingly.

4. Data Sharing

AIQOLA Survey Field Tools does not automatically share survey or project data with AIQOLA or third parties.

Users may voluntarily export or share files through Android system file, storage, or sharing functionality.

When a user chooses to send an exported file through another application or service, the selected third-party service is responsible for its own data handling practices.

5. Support and Feedback

Users may voluntarily contact AIQOLA through:

hello@aiqola.com

Information included voluntarily in a support or feedback email may be used to:

  • respond to the user;
  • investigate a reported issue;
  • provide technical support;
  • improve the application.

Users should avoid sending confidential project information unless necessary for the support request.

6. Advertising, Analytics, and Tracking

The current version of AIQOLA Survey Field Tools does not contain advertising.

The current version does not use advertising tracking.

The current version is not designed to automatically transmit survey work or project coordinates for analytics purposes.

7. Location and Coordinate Data

Users may manually enter, import, calculate, transform, and export geographic or projected coordinates.

These coordinates are used locally for surveying and calculation functions.

AIQOLA Survey Field Tools does not automatically transmit these coordinates to AIQOLA.

8. File Import and Export

The application may allow users to select, create, save, export, or share files using Android system functionality.

Exported data may include TXT, CSV, XLSX, DXF, or other supported survey formats.

The user controls where exported files are stored or shared.

9. Data Retention and Deletion

Application data stored locally remains on the user's device until the user:

  • deletes the relevant project or data;
  • clears application storage;
  • deletes exported files;
  • or uninstalls the application.

AIQOLA does not maintain a server-side account database for the current version of the application.

Support and feedback correspondence may be retained only for as long as reasonably necessary to respond to inquiries, investigate technical issues, maintain support records, or meet applicable legal obligations.

Users may request deletion of information voluntarily sent to AIQOLA by contacting:

hello@aiqola.com

10. Security

AIQOLA Survey Field Tools is designed so that core survey calculations and project data remain locally on the user's device.

Users are responsible for protecting:

  • their device;
  • project data;
  • exported files;
  • backups;
  • and files voluntarily shared with third-party services.

AIQOLA recommends using appropriate device security and project data backup practices.

11. Professional Use

AIQOLA Survey Field Tools is a professional calculation and field-support tool.

Users remain responsible for confirming the correct:

  • datum;
  • coordinate reference system;
  • transformation parameters;
  • control points;
  • Survey Procedure;
  • Project Coordinate Specification;
  • and project requirements.

The application does not replace professional judgment or project-specific survey requirements.

12. Children's Privacy

AIQOLA Survey Field Tools is intended as a professional surveying and engineering tool and is not directed toward children.

13. Changes to This Privacy Policy

This Privacy Policy may be updated if application functionality, data practices, applicable laws, or Google Play requirements change.

The latest version will be published on the official AIQOLA website.
